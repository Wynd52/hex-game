Hex-game
Game of hex with PvP and PvC setting for killing time.
## Installation
# Clone the repository
git clone https://github.com/Wynd52/hex-game.git
cd hex-game
# Create virtual environment
python -m venv venv
source venv/bin/activate
# Install dependencies
pip install -r requirements.txt
## Usage
Star run main.py
size of board can be change in main.py by writing different number in hex_grid()
## Requirements
- Python 3.13+
- See `requirements.txt` for package dependencies
